# ProfishNal Watcher

A media library management app for tracking movies, TV shows, and entertainment content with intelligent scoring.

## Features

- **Media Library** - Organize and browse your entertainment collection
- **Search Functionality** - Find media quickly with advanced search
- **Admin Panel** - Manage library content and settings
- **Import/Export** - Backup and restore your library
- **Scoring Engine** - Rate and rank media with custom algorithms
- **User Profiles** - Track individual preferences and viewing history
- **Authentication** - Secure login via Supabase

## Tech Stack

- **Frontend**: React 19, Zustand (state management)
- **Backend**: Node.js API
- **Database**: Supabase
- **External API**: IMDb integration

## Setup

```bash
# Install dependencies
npm install

# Start development server
npm start
```

The app will open at `http://localhost:3000`

## Build

```bash
npm run build
```
